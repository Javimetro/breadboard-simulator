# Breadboard Lab

Learn how a breadboard works by building real circuits, in your browser, on phone or computer.

- 12 levels: inside the breadboard, power rails, first LED, common mistakes, push button, dimmer knob, MB102 power supply and Ohm's law, multimeter, Arduino Nano, light meter on an OLED, clap-to-beep, and the ESP32 5V danger.
- Sandbox with every part: LEDs, resistors, button, potentiometer, capacitor, 9V and AA batteries, MB102, multimeter, Arduino Nano, ESP32 Feather (HUZZAH32), Wio Terminal, Raspberry Pi 5, LDR, DHT11, HC-SR04, PIR, microphone, OLED, 16×2 LCD, 7-segment, buzzer, speaker.
- Real electrical simulation (nodal analysis with a non-linear LED model).

Play: https://javimetro.github.io/breadboard/ (or open `breadboard-lab.html` directly).
